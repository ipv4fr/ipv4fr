### ipv4.fr

Network and web data tools for developers and AI agents.

- REST API: DNS, WHOIS, TLS, email validation, IP geolocation, blacklists, HTTP headers. [Docs](https://ipv4.fr/docs.html)
- x402 pay-per-call in USDC on Base, no account needed: [ipv4.fr/x402/v1](https://ipv4.fr/x402/v1)
- MCP server: `https://ipv4.fr/mcp` (registry name `fr.ipv4/network-tools`)
- Free browser tools: [ipv4.fr/tools](https://ipv4.fr/tools)

Start here: [ipv4fr/ipv4-fr-tools](https://github.com/ipv4fr/ipv4-fr-tools). Contact: contact@ipv4.fr
